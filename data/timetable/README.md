# 時間割データ（クラス別の曜日時限を解決するための手作業入力ファイル）

## これは何のためのファイルか

`data/subjects/youran-2025.json` の `offerings`（`scripts/fetch_syllabus.py` がシラバスWeb公開システムから
取得したもの）には、1つの科目に複数のセクション（クラス）がある場合、各セクションの担当教員・曜日時限は
分かるが、**そのセクションがどのクラス（1年次クラス1〜12、Ⅰ類のA/B/Cクラスなど）の学生向けかは分からない**。

一方、`https://kyoumu.office.uec.ac.jp/timet/A1.pdf` 〜 `A8.pdf`（学期ごとの時間割表）には、
「このクラスのこの曜日時限にはこの科目・この教員」という格子状の情報が載っている。

このフォルダの `class_schedule.csv` に、そのPDFの格子を1行ずつ書き起こしたものを溜めていく。
`class_schedule.csv` の担当教員名と `offerings` の担当教員名を突き合わせれば、
「学籍番号→1年次クラス→（このCSV経由で）曜日時限」が機械的に決まるようになる
（この突き合わせスクリプト自体はまだ書いていない。CSVが埋まってから書く）。

**このフォルダの作業は画像認識（PDFを読んで書き起こす部分）を別途行う前提。**
このREADMEと`class_schedule.csv`はその受け皿（テンプレート）。

## 対象PDFと、そのPDFで使われるクラス表記（`class_id`列に何を書くか）

CLAUDE.mdの進捗ログ（2026-09-05時点の調査）より。曖昧な場合はCLAUDE.mdの該当箇所を確認すること。

| pdf | 学年・学期 | 対象クラス（`cluster`列 / `class_id`列の値） |
|---|---|---|
| A1 | 1年前期 | 全類共通の`class_id`＝`1`〜`12`（`1`〜`4`=Ⅰ類、`5`〜`8`=Ⅱ類、`9`〜`12`=Ⅲ類） |
| A2 | 1年後期 | 同上。ただしⅠ類の第二外国語など一部科目だけ、`class_id`に`A`/`B`/`C`（クラス1-12とは別軸）が出てくることがある。両方の情報がある科目は行を分けて2行書く |
| A3 | 2年前期 | Ⅰ類＝`A`/`B`/`C`、Ⅱ類＝`I1`〜`I6`または`M`、Ⅲ類＝`1`〜`4` |
| A4 | 2年後期 | 基本は`class_id`＝プログラム名（例:`メディア情報学プログラム`）。Ⅰ類の一部科目（アルゴリズム論第一など）だけ`A`/`B`/`C`が生きている。Ⅲ類は`Mエリア`または`Sエリア`（Sエリアの中はさらにプログラム名）。プログラム内でさらにクラス分けがある科目（例:電子工学プログラムの基礎電子回路）は`class_id`を`電子工学プログラム/クラスA`のように`/`で連結する |
| A5〜A8 | 3年前期〜4年後期 | 基本は`class_id`＝プログラム名のみ。学籍番号の偶数/奇数でさらに分かれる科目（A6で確認済み）は`class_id`を`計測・制御システムプログラム/偶数`のように書く |

学籍番号の偶奇は`profile.yearOneClass`（1年次クラスの数字）の偶奇と対応する
（`src/storage/profile.ts`のコメント参照）。

## `class_schedule.csv` の列

| 列名 | 内容 | 例 |
|---|---|---|
| `pdf` | 出典PDF | `A1` |
| `year` | 標準学年（1〜4） | `1` |
| `term` | `前学期`／`後学期` | `前学期` |
| `cluster` | `I`／`II`／`III`（夜間主等クラス制度が無い場合は空欄） | `I` |
| `class_id` | 上表の表記ルールに従ったクラス識別子 | `3` |
| `day` | `月`/`火`/`水`/`木`/`金`/`土`/`日` | `木` |
| `period` | 時限（1つの数字。3〜4限にまたがる科目は`period`違いで2行に分ける） | `3` |
| `subject_name` | 時間割の科目名（そのまま転記。科目コードへの変換は後工程） | `基礎科学実験A1` |
| `teacher_name` | 時間割に書かれた教員名（`offerings`側の`instructors`と突き合わせるキーになるので、可能な限り正確に） | `加固　昌寛` |
| `note` | 教室・隔週・再履修クラスなど、気づいたことがあれば自由記述（無ければ空欄） | |

- 1行＝1クラス・1曜日・1時限。同じ科目でも曜日時限が違えば行を分ける
- 空きコマ（何も開講されていない）は書かなくてよい
- 「教職科目」「上級科目」などの注記だけの行、複数プログラム共同開講で列がまたがっている行は、
  実際に文字が書かれている列（プログラム名など）ごとに行を分けて書く
- 迷ったら`note`列に状況を書いておけば後で判断できる

## 埋め終わったら

`class_schedule.csv`が埋まったら、`offerings`の`instructors`と`teacher_name`を突き合わせて
`class_id`→`timetableCode`を決定するスクリプトを書く（未着手）。それができれば、
プロフィールで入力したクラス情報から、複数セクションがある科目でも正しい曜日時限を
一意に表示できるようになる。
