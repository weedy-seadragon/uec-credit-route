# 学修要覧PDFの読み方（AIエージェント向けの実務メモ）

このプロジェクトのデータ（`data/requirements/`・`data/subjects/`）は、大学が配布する
学修要覧PDFを人間が目視確認しながら手で書き起こしたもの。原本PDFは著作物のため
リポジトリには含めていない（`.gitignore`の`*.pdf`で除外）ので、開発者のPC上のファイルを
直接読む必要がある。このファイルは、過去のセッションで確立した「実際に機能した読み取り手順」の
まとめ。人間の開発者は読まなくてよい（`docs/HANDOVER.md`の対象外）。

## 読み取り手段の選び方

1. **`pdftotext.exe`（Git for Windowsのmingw64に同梱）は使えない**：このPDFのフォントだと
   日本語グリフが空白になって読めない（英数字・記号だけは正しく取れる）
2. **数字だらけの横長の表（別表2など）は `pdftotext -layout` が確実**：科目コード・数字は
   正しい位置に出力されるので、既知の1行（例: 全プログラム共通で同じ値が並ぶ行）で各列のX座標を
   較正し、そのX座標に一番近いトークンを他の行にも割り当てれば、表を機械的に復元できる
3. **科目名など日本語そのものを読む必要がある表は、ページを画像化して目視確認する**。2つの方法がある：
   - **poppler の `pdftoppm`**（推奨、こちらの方が速い）：
     `winget install oschwartz10612.Poppler` で導入済みのはずだが、無ければ上記コマンドで入れる。
     フルパスは
     `C:\Users\maita\AppData\Local\Microsoft\WinGet\Packages\oschwartz10612.Poppler_Microsoft.Winget.Source_8wekyb3d8bbwe\poppler-25.07.0\Library\bin\pdftoppm.exe`
     （バージョン番号は変わりうるので、無ければ`Get-ChildItem`等で探す）。使い方：
     ```
     pdftoppm.exe -png -r 200 -f <開始ページ> -l <終了ページ> <PDFパス> <出力先プレフィックス>
     ```
     `-r 200`（200dpi）で大抵は読める。密な表は`-r 300`にしてPython/PILで縦4分割すると文字が潰れない。
     出力されたPNGをReadツールで開いて目視する
   - **Playwrightの内蔵Chromium PDFビューア**（pdftoppmが使えない環境向けの代替）：
     `chromium.launch({ headless: false })` → `page.goto('file:///<pdfパス>#page=N&zoom=150')` →
     `page.screenshot()`。**`headless: true`だとPDFが「ダウンロード」扱いになり開けないので
     必ず`headless: false`にする**
4. ページ番号は**PDFの物理ページ番号**を使うこと（本文中の印刷ページ番号「-NN-」とは一致しない。
   抜粋版のため）
