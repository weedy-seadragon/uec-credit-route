# 学修要覧2025・2026 データ差分調査

調査日: 2026-09-08

## 結論

- 別表2の卒業所要単位は、昼間コース15プログラムすべてで2025年度版と2026年度版が同じだった。
  - Ⅰ類5プログラム: 128単位
  - Ⅱ類5プログラム: 133単位
  - Ⅲ類5プログラム: 133単位
- 審査条件のページにも、サイトの判定値を変更する必要がある数値差分は見つからなかった。
- 差分は主に付録Cの科目表にあり、新設・廃止・科目番号の整理が行われている。
- 2026年度用として、共通要件・昼間15プログラム・夜間主の計17要件ファイルと科目マスタを生成した。
- 比較中に、2025年度データから情報通信工学プログラムの選択科目5件が漏れていたことも判明したため、2025年度・2026年度の両方へ修正を入れた。

## 比較方法

1. `PDF/yoran_2025.pdf` と `PDF/youran2026-gakuiki_trimmed_high_quality.pdf` の全54ページをページ対応で確認した。
2. 卒業要件・審査条件は本文と別表2～4、科目差分は付録C（18～54ページ）を重点的に比較した。
3. PDFの文字抽出結果だけに依存せず、差が疑われたページは画像化して表の行・科目番号・単位数・開講学期を目視確認した。
4. 生成後のJSONは `scripts/validate_data.py` で、年度ごとに科目参照・必修単位合計・小計・審査条件を検証した。

## 確認できた差分

### 共通科目

- 海外研修の新しい科目番号が追加された。
  - `INT006z` 海外研修Ⅰ（1単位、1～8学期で履修可）
  - `INT007z` 海外研修Ⅱ（2単位、1～8学期で履修可）
- 従来の `INT004z` 海外語学研修Ⅰ、`INT005z` 海外語学研修Ⅱも残っている。
- `INT006z`・`INT007z` は、従来の海外語学研修と同様に共通単位へ直接算入する扱いにした。
- `HSS321z` 論理学は2026年度版の付録Cに掲載されている。これは先行調査ですでに現在の科目マスタと共通要件へ追加済みだったため、今回の追加差分には含まれない。

### Ⅰ類 情報数理工学プログラム

- `MTHa02c` プログラム言語基礎論（2単位、4年次後学期、大学院連携・自由科目）が追加された。
- 大学院連携科目の番号が次のように整理された。
  - `MTHb01c`: ハイパフォーマンスコンピューティング基礎論 → シミュレーション理工学基礎論
  - `MTHb02c`: シミュレーション理工学基礎論 → 離散最適化基礎論
  - `MTHb03c`: 離散最適化基礎論 → 連続最適化基礎論
  - `MTHb04c` 連続最適化基礎論は旧番号として廃止
- つまり、ハイパフォーマンスコンピューティング基礎論が科目表から外れ、後続3科目の番号が1つずつ繰り上がった形になる。

### Ⅱ類 情報通信工学・電子情報学プログラム

- 2025年度版では `ELE505g/h` が「宇宙通信工学」と「マルチメディア処理」の両方に使われており、フルコードを主キーにする現在のデータ形式では両方を保持できなかった。
- 2026年度版では次のように番号が分離され、この重複が解消された。
  - `ELE505g/h` 宇宙通信工学（従来どおり）
  - `ELE506g/h` マルチメディア処理（新しい番号、2単位、3年次前学期、大学院連携・自由科目）
- したがって `ELE505g/h` を置換せず、`ELE506g/h` を追加するのが正しい。

### Ⅱ類の2025年度データで見つかった欠落

次の5科目は2025・2026の両方の情報通信工学プログラム表に載っているが、既存の科目マスタと要件JSONから漏れていた。

- `ELE604g` 符号理論
- `ELE605g` 伝送回路論
- `ELE606g` 電磁波工学
- `PHO601g` 光通信工学
- `ELE607g` 通信システム学

いずれも2単位・3年次後学期の類専門選択科目である。Ⅱ類では他プログラムの類専門選択科目も履修できるため、情報通信工学だけでなくⅡ類5プログラムすべての `major-sel` へ展開した。生成元の `scripts/gen_data.py` にも追加したため、将来の再生成で消えない。

### Ⅲ類4プログラムのサイエンス工房

電子工学・光工学・物理工学・化学生命工学では、次の科目が類専門選択科目として追加された。

- `GSE201m/n/p/r` サイエンス工房B（1単位、標準2学期）

同じ4プログラムでは、次のUECパスポートプログラム科目が2026年度の科目表から外れた。

- `UEC302m/n/p/r` UECパスポートプログラムA
- `UEC501m/n/p/r` UECパスポートプログラムB
- `UEC701m/n/p/r` UECパスポートプログラムC

Ⅲ類では他プログラムの類専門選択科目も算入できるため、サイエンス工房8コードは機械システムを含むⅢ類5プログラムすべての選択科目一覧へ展開した。

## 実装したもの

- `scripts/build_2026_data.py`
  - 2025年度データを複製し、確認済み差分だけを適用して2026年度データを再生成する。
  - 変更のない科目は既存の2026年度シラバス情報を引き継ぐ。
  - 新設・番号変更科目は、別科目のURLを誤って出さないよう `offerings` を空のままにする。
- `data/requirements/2026-*.json`
  - 共通1件、昼間15件、夜間主1件。
- `data/subjects/youran-2026.json`
  - 1,394科目。
- `scripts/validate_data.py`
  - 2025年度と2026年度を同時に検証するよう拡張。
  - 今回確定した2026年度固有の追加・廃止も回帰検査する。

## サイトへ表示する前に残る作業

2026年度データ自体は生成・検証できているが、プロフィール設定で2026年度を選べる状態にはまだしていない。現在の画面は科目マスタを1年度分だけ読み込む設計であり、単に入学年度欄を表示すると、2026年度要件と2025年度科目名が混在する可能性があるためである。

今回、`MTHb01c` や `MCEb03k` のように、**同じフルコードが翌年度には別の科目名を指す**例が実際に見つかった。このため、年度をまたいだ主キーは科目番号だけでは足りず、`(入学年度, 科目番号)` の組として扱う必要がある。単純なコード変換表では逆に誤結合する可能性があるため、この設計判断を`docs/SPEC.md`にも追記した。

表示対応では次をまとめて行う必要がある。

1. 入学年度に応じて科目マスタと昼間共通要件を切り替える。
2. 科目一覧・科目詳細ページでも年度を保持し、同じ科目番号で名称が変わった場合に正しい年度の名称を表示する。
3. 2026年度の新設・番号変更科目について、2026年度シラバスの正しいURL・曜日時限を取得する。
4. 代表的な差分（MTHb系列、ELE505/506、サイエンス工房、MCEb系列、BCHa03/04）の画面テストを追加する。
5. 上記完了後にプロフィール設定の入学年度欄を有効化する。

この順序なら、2026年度を選べるようにした瞬間から、要件計算・科目名・リンクの年度が一貫する。
