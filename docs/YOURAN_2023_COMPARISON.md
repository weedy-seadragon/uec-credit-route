# 学修要覧2023・2024 データ差分調査

調査日: 2026-09-14

## 経緯

2021〜2023年度データ（`scripts/build_2021_data.py`〜`build_2023_data.py`）はCodeXが追加したもの。
`build_2023_data.py`は「付録Cと別表2を照合した範囲では、2023年度の科目表・卒業要件は2024年度版と
同じ構成だった」というコメントで2024年度データをそのまま複製していたが、開発者から「vague（漠然と
した）バグ探しの負担」について相談を受けた際、①自動整合性チェック（`validate_data.py`）は年度をまたぐ
コード意味の食い違いのような分類バグを検出できないことを説明し、実例として過去のデザイン思考・
データサイエンスプログラムの再編（2024→2025、`docs/YOURAN_2024_COMPARISON.md`参照）を挙げたところ、
「2023年度も同様に検証してほしい」と依頼された。

学修要覧2023の付録C C.3.1⑤（デザイン思考・データサイエンスプログラム）を画像で確認したところ、
`check_known_2023_values`（CodeXが追加した回帰検査）が期待していた「必修19・選択17」は誤りで、
実際は**必修20・選択16**だった。

## 確認できた差分

デザイン思考・データサイエンスプログラムの類専門科目に、2024年度には無い独立必修科目
「**データサイエンス演習**」（COM502e、1単位、3年次前学期）が存在する。この科目が割り込むため、
以降のCOM50Xeが2024年度から1つずつ番号がずれている。

| 科目名 | 2023年度 | 2024年度 |
|---|---|---|
| データサイエンス演習（必修、新規） | COM502e | （無し） |
| データサイエンス実践演習１（必修） | COM503e | COM502e |
| データサイエンス実践演習２（必修） | COM701e | COM701e（変更なし） |
| オペレーティングシステム論（選択） | COM504e | COM503e |
| メディア分析法（選択） | COM505e | COM504e |
| マルチメディア処理（自由科目） | COM506e | COM505e |

その他の変更点：
- 自由科目から「情報工学工房B」（COM002e）・「情報工学工房C」（COM003e）・「GLTPラボワーク」
  （LAB501e）が無い。選択科目の「情報工学工房」（COM001e）はA/B/Cに分かれていない
- 類専門必修19→20単位、選択17→16単位（小計36単位・専門小計77単位は変わらない）
- デザイン思考概論（INS601e）・システム思考概論（INS701e）はどちらも2024年度と同じ内容・単位数

上記以外（理数基礎科目・類共通基礎科目・自プログラム以外の選択科目一覧・自由科目の大学院連携科目群・
国際科目）は2024年度と同一だった。

## 実装したもの

- `scripts/build_2023_data.py`：`update_designds_requirement()`と`copy_subject_master()`の
  COM50Xe振り直し処理を追加し、再生成しても正しい値になるようにした
- `data/requirements/2023-day-I-designds.json`：`major-req`required 19→20（COM503e追加）、
  `major-sel`required 17→16（COM503e→COM504e、COM504e→COM505e）、`major-free`からCOM002e・
  COM003e・LAB501eを除去しCOM505e→COM506eへ変更
- `data/subjects/youran-2023.json`：COM502e〜506eの名称・区分を修正（COM503eのofferings/
  prerequisitesTextはオペレーティングシステム論の実データとしてCOM504eへ引き継いだ）
- `scripts/validate_data.py`：`check_known_2023_values`の期待値を19/17→20/16に修正し、
  COM502e〜506eの科目名も回帰検査に追加

## Ⅰ類残り4プログラム（メディア情報学・経営社会情報学・情報数理工学・コンピュータサイエンス）

2023年度のC.3.1（Ⅰ類、22〜30ページ）を2024年度と画像照合した。デザイン思考・データサイエンスほど
大きな差分ではないが、**Ⅰ類5プログラム共通の差分が2件**見つかった。

### Ⅰ類5プログラム共通（media/management/mathinfo/cs/designds）

- **情報工学工房がA/B/Cに分かれていない**：2023年度は「情報工学工房」（COM001x、選択科目）の
  1科目のみ。2024年度に「情報工学工房A」（COM001x、選択）へ改称され、「情報工学工房B」
  （COM002x、自由科目）・「情報工学工房C」（COM003x、自由科目）が新設された
- **GLTPラボワーク（LAB501x）が無い**：2024年度に自由科目として新設された

（xはプログラムごとの末尾記号：メディア情報学=a、経営・社会情報学=b、情報数理工学=c、
コンピュータサイエンス=d、デザイン思考・データサイエンス=e）

### メディア情報学プログラム固有

- 現代代数学・数理解析学（大学院連携科目）が自分専用の番号（MTHb02a/MTHb03a）を持たず、
  経営・社会情報学プログラムの番号（MTHb02b/MTHb03b）をそのまま参照している。2024年度に
  メディア情報学専用のMTHb02a/MTHb03aへ分離された

### 変更が見つからなかった範囲

上記2件以外（理数基礎科目・類共通基礎科目・類専門必修/選択必修/選択の科目一覧・自由科目の
その他の大学院連携科目群・国際科目・別表2の単位数）は、メディア情報学・経営社会情報学・
情報数理工学・コンピュータサイエンスの4プログラムとも2024年度と同一だった。

### 実装したもの（追加分）

- `scripts/build_2023_data.py`に`update_first_cluster_requirements()`・
  `update_first_cluster_subjects()`を追加し、Ⅰ類5プログラム（designds含む）共通の
  情報工学工房B・C・GLTPラボワーク除去と、メディア情報学のMTHb02a/MTHb03a→MTHb02b/MTHb03b
  差し替えを反映した
- `scripts/validate_data.py`に対応する回帰検査を追加
- `src/data/requirementSets.test.ts`にメディア情報学の差分を検証するテストを追加

## Ⅱ類5・Ⅲ類5プログラムと夜間主課程（2026-09-14）

### 副次的に見つかった2024年度データの不具合

Ⅲ類の電子工学（m）・光工学（n）の照合中に、2024年度データ自体の不具合を1件発見した。
「画像情報学基礎」は本来、電子工学（ELEa02m、2024年度新設）と光工学（ELEa02n、
2023年度以前から存在）で別々の科目のはずだが、光工学のELEa02nは学修要覧2024の原本
付録C（`youran2024.pdf`）の光工学プログラムの科目表には掲載が無い（2025年度の付録Cには
再掲載される）。科目マスタにELEa02n自体が載っていることは問題ではない（シラバスに基づく
実在科目であり、`data/subjects/youran-2024.json`にあること自体は妥当）。問題は
`2024-day-III-optical.json`（2024年度入学者の要件ファイル）がこれを自由科目として
参照していること：卒業要件は入学年度の学修要覧原本にマストで従うべきところ、2024年度
入学者にこの科目を自由科目として認めてよい根拠が原本に無い。`docs/YOURAN_2024_COMPARISON.md`
の2024↔2025照合でもこの差分が見落とされていた。2023年度データにはELEa02nをそのまま
引き継いでいるが、2023年度の原本にはこの科目が掲載されているため2023年度としては正しい。
2024年度の要件ファイルの修正は本調査のスコープ外のため今回は着手していない。

## 未確認（2021・2022年度）

CodeXが追加した2021・2022年度データは今回まだ画像照合していない。`build_2021_data.py`は
「2021年度は2022年度と専門科目の構成が共通」、`build_2022_data.py`は「デザイン思考・
データサイエンスプログラムがまだ無い」とコメントしている。2023年度は昼間15プログラム＋
夜間主の16課程すべてで実際に差分が見つかった実績があるため、確認するまでは
「①自動整合性チェックは通っている」以上の保証はできない。
